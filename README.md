# pear-electronics-website

A multipage electronics retail website developed as part of IT 213 – Multimedia & Web Design at George Mason University.

## Project Overview
Pear Electronics is a fictional electronics company website designed to demonstrate web development, multimedia integration, and user-friendly navigation.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Adobe Dreamweaver
- Adobe Photoshop
- Adobe Animate

## Features
- Multipage website with organized navigation
- Product and service information
- Promotional content and animations
- Accessibility features, including alternative text and skip navigation links
- Contact and site map pages
